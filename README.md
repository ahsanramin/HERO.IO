## 📖 About The Project
HERO.IO is a premium, highly animated, SaaS-level platform showcasing the best productivity applications. Built as part of a rigorous assignment, it goes above and beyond by implementing enterprise-grade UI/UX patterns, buttery-smooth animations, and robust state management.

### 🎯 Key Features
- **Massive SaaS Home Page:** 13+ fully animated sections including Hero, Stats, Features, Categories, Top Experts, Testimonials, Blog, Pricing, FAQ, Newsletter, and CTA.
- **God-Tier UI/UX:** Glassmorphism, noise textures, animated gradient meshes, magnetic buttons, and letter-by-letter text reveals.
- **Live Search & Sorting:** Instantly filter apps by title or sort them by download count (High-Low / Low-High).
- **App Details & Charts:** Beautifully rendered App Details page with a fully responsive Recharts bar chart visualizing user ratings.
- **Local Storage Installation:** "Install" any app to save it to your local device. Uninstall it directly from the "My Installations" dashboard.
- **5 Additional Pages:** About, Contact, Blog, Help/Support, and Privacy/Terms.
- **Dynamic Theme Toggle:** Seamless Dark/Light mode switching using `next-themes`.
- **Custom 404 Page:** A beautifully designed fallback page for missing routes.
- **100% Responsive:** Meticulously crafted to look perfect on mobile, tablet, and desktop screens.

## 🛠️ Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS (v4)
- **Animations:** Framer Motion
- **Charts:** Recharts
- **Notifications:** React Hot Toast
- **Icons:** Lucide React
